## 1. 本次修改

- **内容**：门店自检证明中文瘦长靠 `GS ! 0x01`（ZH B GS!1x2）；旧路径用 `FS ! 0x04` 当初 1×2 → 实际倍宽变扁、列头换行。出纸与自检统一为 `HanFirmwareLine` + `GS !`。
- **改动点**：`escposenc.HanFirmwareLine`；删 `HanFirmwareSize`；Mesa `escposWriter.text` / FT `emitThermalLine`；`SizeProbeRows`；定稿文档；VERSION/NOTES；样张仍走 `buildStationSampleSlip`→`escposFromJob`（无旁路）。
- **唯一写法（自检，diff 各一份）**：
  - 固件汉字行字节：**仅** `escposenc.HanFirmwareLine(s, FontASize(…), hanMode)`
  - `hanMode`：`0` 或 `HanUnderline`（`FS ! 0x80`，不含字号）
  - Mesa：`escposWriter.text` → 上者；FT：`emitThermalLine` → 上者
  - 自检 ZH B / MIX：只调 `HanFirmwareLine`；`ZH B FS!flat` 为对比行（非出纸路径）
- **不动**：`text_encoding=bitmap` 逃生；葡语纯 Font A；SAF-T。

## 2. 核心业务规则

1. 【已实现】含汉字且其余可 GBK/WPC1252 的行走固件 B（`FS &` + GBK + `FS .`）。
2. 【已实现】汉字正文 1×2 与葡语同一 `GS ! 0x01`（瘦长）；抬头 2×2 = `GS ! 0x11`。
3. 【已实现】禁止用 `FS !` 编倍高/倍宽当字号。
4. 【已实现】备注下划线：Font A `ESC -`；汉字段 `FS ! 0x80`。
5. 【已实现】出品联样张 = 正式 `station_ticket` 代码，无第二套排版。
