## 1. 本次修改

- **内容**：落地 GR（发货/交货单）：签发前 mock AT 运输通信 → 本机占号/Hash/ATCUD；可作废（仅 N→A）；开 FT 时可挂 1..N 张 GR；进 SAF-T `MovementOfGoods`；不计入营收。
- **改动点**：`014_gr_delivery.sql`；`at.TransportClient`；`store.IssueGR` / `AnnulGR` / `linkDeliveryNotesInTx`；`service.IssueDeliveryNote`；manual API `document_type=GR`；打印前缀 `Guia de remessa:`；Admin Tab/系列/手工字段；`scripts/fiscal-gr-regression.mjs`。
- **唯一写法（自检，diff 各一份）**：
  - 签发：`service.IssueDeliveryNote` → `store.IssueGR`
  - 作废：`service.AnnulDeliveryNote` → `store.AnnulGR`
  - FT 挂 GR：`IssueFT` 事务内 `linkDeliveryNotesInTx`
  - AT 运输：`at.TransportClient.RegisterDocument`（仅 IssueDeliveryNote 调用）
- **不动**：GT；live AT SOAP（G7 blocked）；堂食强制插 GR；FS/FR 挂 GR。

## 2. 核心业务规则

1. 【已实现】无 ACTIVE GR 系列 → `series_missing`；无 GR 系列不挡 FT `ready_to_issue`。
2. 【已实现】签发前必须拿到 `ATDocCodeID`（mock 伪码 `MOCK…`）；失败整单失败。
3. 【已实现】收货方名称+地址必填；IVA 纳税人须真实 NIF（禁止静默 `999999990`）。
4. 【已实现】状态机 N→F（被 FT 引用）/ N→A（作废）；F/A 不可作废；A 不可再挂。
5. 【已实现】一张 GR 可被多张 FT 引用；金额不必轧平；仅 FT 可带 `delivery_note_ids`。
6. 【已实现】营收汇总排除 GR；SAF-T 进 `MovementOfGoods`，不进 `SalesInvoices`。
