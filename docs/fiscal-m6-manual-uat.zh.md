## H1 — Admin 单据类型（C2.2-UI）

1. 打开 Admin → **手工开票**（或订单/商品开票入口里选类型的地方）。  
2. 看单据类型下拉：**只能看到 FT、FS**，没有 FR / NC / ND。  
3. 不选类型直接开一张 → 应为 **FS**（默认）。  
4. 再显式选 **FT** 开一张，票号前缀为 FT。

## H2 — 扫枪读 QR（C2.6-scan）

1. 开一张 **FS**（或 FT），等热敏 ORIGINAL 出纸。  
2. 用扫枪（或手机扫码 App）扫票面二维码。  
3. 扫枪应有「嘀」/读出字符串；内容中应能看到与票面一致的 **ATCUD**（形如 `XXXXXXXX-n`）。  
4. 对照 Admin 发票详情里的 ATCUD，二者一致。

|------|-----------------|--------|

## H3 — 真热敏出纸（C5.3-hw）

1. 确认税务打印机在线；开一张 FS。  
2. 纸面应有：店名、行项目、合计、**ATCUD**、Hash 控制字符、二维码。  
3. Admin 该票打印状态为已打印（或等价文案）；可再点 **重打**，出副本且详情 **Hash 不变**。

## H4 — 换机（可选，C7.2-hw）

仅在有第二台机或愿意做停用演练时做。

**旧机**

1. 设置 → **8. 备份与换机** → **备份税务库**，记下路径。  
2. 点 **本机停用开票授权（换机）** → 确认；就绪状态「已激活」应变否。  
3. 拷走备份 `.db` 文件。

**新机**

4. 安装同版本 Agent；**先停进程**，用备份替换 `fiscal.db`（若有 `-wal`/`-shm` 一并删掉或不要混用）。  
5. 启动 → 设置 → **校验系列完整性** → 应通过。  
6. **从运营同步开票授权**（或 UAT 本地 PEM）→ 可再开一张票。
