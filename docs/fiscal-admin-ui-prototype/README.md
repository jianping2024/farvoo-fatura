# Farvoo 开票 · UI 交互原型 v2

> **状态：草稿（流程对齐稿）**  
> **权威：否** — 用于对齐产品流程与界面，未接 API。

## 设计原则（v2）

1. **先有订单，后有发票** — 手动开票同样：新建订单 → 加商品 → 确认 → 选发票类型 → 签发。
2. **业务语言** — 界面不出现「草稿、LOCAL、API、M3」等开发词；餐馆侧收银同步叫 **「待开票账单」**。
3. **业态分离** — 登录时选 **餐馆 / 商超**；导航与首页按模式显示不同入口（如餐馆才有「待开票账单」）。
4. **流程可见** — 订单/开票页顶栏 **四步进度条**：创建订单 → 添加商品 → 确认订单 → 开票。

## 打开

open docs/fiscal-admin-ui-prototype/index.html

## 可点路径

| 步骤 | 餐馆 | 商超 |
|------|------|------|
| 登录 | 选餐馆 + PIN | 选商超 + PIN |
| 工作台 | 新建订单 / 待开票账单 | 新建订单 |
| 订单 | 列表 → 继续开票 | 同左 |
| 新建订单 | 桌号 + 商品 + 确认 | 收银台 + 商品 + 确认 |
| 开票 | 选 FT + 购方 + 打印 | 同左 |
| 待开票账单 | 收银同步 → 转订单 | （无此菜单） |

## 与实现的映射（讨论用，不在 UI 展示）

|--------------|--------------|
