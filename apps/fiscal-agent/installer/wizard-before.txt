Before you install
==================

Version
  The Setup window title shows this build as: Farvoo Fiscal Agent + version
  (example: "Farvoo Fiscal Agent 0.3.95"). Confirm it matches the release you
  downloaded before continuing.

Administrator / upgrade
  This Setup asks for administrator permission so it installs under Program Files
  and can update an existing Farvoo Fiscal Agent (same Add or Remove Programs entry;
  also upgrades a prior Mesa Print Agent install that shared this AppId).
  If the agent is already running, Setup stops FarvooFiscalAgent.exe (and legacy
  MesaPrintAgent.exe) automatically before replacing files (no separate "please exit"
  / yes-no close step). Continue with Next.

SmartScreen (unsigned build)
  Windows may show "Unknown publisher". Click More info, then Run anyway.
  Or: right-click the installer → Properties → check Unblock → OK.

USB printers (UNYKA UK56009, etc.)
  Install the vendor driver first so the printer appears in Windows Settings → Printers.
  Driver info: https://unykach.com/

Portable zip vs this Setup
  This installer offers optional desktop and sign-in shortcuts on the tasks step,
  plus clean uninstall. Portable zip has no wizard — use Setup for daily POS PCs.

Configuration flow
  This installer only installs and starts the local tray agent (print + fiscal).
  Pairing and printer mapping are done from Farvoo Dashboard → Print assistant
  (pairing page + printer settings page in the browser; scan printers manually).
  Fiscal setup (taxpayer / series / activate) is at http://127.0.0.1:17880/ when the
  agent is running. A test print is recommended but not required to close the page.
